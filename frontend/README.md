# Frontend

React 19 + TypeScript + Vite client for the ESPN 9-cat Draft Copilot. It talks to the FastAPI backend
over `/api` (proxied by Vite in development; set `COPILOT_BACKEND` to point at another port).

```
npm ci              # install
npm run dev         # dev server (use `make dev` from the repo root to start both halves)
npx vitest run      # unit tests
npx tsc --noEmit -p tsconfig.app.json
npx playwright test # e2e against a real backend on a temp data dir (see playwright.config.ts)
```

Layout: `src/screens` (Setup, Draft, Recap, Season, Performers, Data health), `src/components/*`,
`src/store` (zustand), `src/api` (typed client; `schema.d.ts` is generated by `make openapi`).
